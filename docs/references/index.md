# References

This section collects standards, protocol specifications, papers, tools, and external documentation relevant to the Agentic Web Stack.

Reference pages should prioritize primary sources:

- official standards and RFCs
- protocol specifications and repositories
- academic papers
- vendor documentation for concrete tools and APIs
- vendor-neutral explainers when no primary source exists
