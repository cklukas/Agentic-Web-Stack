# Standards

## Discovery and Web Metadata

- [RFC 8615: Well-Known Uniform Resource Identifiers](https://www.rfc-editor.org/rfc/rfc8615) - convention for predictable `/.well-known/` metadata locations.
- [RFC 9309: Robots Exclusion Protocol](https://www.rfc-editor.org/rfc/rfc9309) - standard behavior for `robots.txt`.
- [Sitemaps XML format](https://www.sitemaps.org/protocol.html) - conventional URL discovery for crawlers and indexers.

### Emerging Community Proposals

- [llms.txt](https://llmstxt.org/) - proposed Markdown entry point to documentation for agents. See the [local concept page](/concepts/llms-txt) for its place in Layer 1 and its trust boundaries. This is a community proposal rather than a formal web standard.

## Identity and Authorization

- [RFC 6749: OAuth 2.0 Authorization Framework](https://www.rfc-editor.org/rfc/rfc6749) - delegated authorization foundation.
- [RFC 6750: OAuth 2.0 Bearer Token Usage](https://www.rfc-editor.org/rfc/rfc6750) - bearer token usage over HTTP.
- [RFC 7519: JSON Web Token](https://www.rfc-editor.org/rfc/rfc7519) - compact claims format for tokens.
- [OpenID Connect Core](https://openid.net/specs/openid-connect-core-1_0.html) - identity layer built on OAuth 2.0.

## APIs and Schemas

- [RFC 9110: HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110) - core HTTP semantics.
- [OpenAPI Specification](https://spec.openapis.org/oas/latest.html) - machine-readable HTTP API descriptions.
- [JSON Schema](https://json-schema.org/) - schema vocabulary for JSON data.
- [GraphQL Specification](https://spec.graphql.org/) - query language and execution semantics for GraphQL APIs.

## Knowledge Representation

- [RDF 1.1 Concepts](https://www.w3.org/TR/rdf11-concepts/) - resource description model for graph data.
- [SPARQL 1.1 Query Language](https://www.w3.org/TR/sparql11-query/) - query language for RDF graphs.
