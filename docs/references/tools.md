# Tools

## Documentation

- [VitePress](https://vitepress.dev/) - Markdown-first static documentation site generator.
- [VitePress Plugin Mermaid](https://emersonbottero.github.io/vitepress-plugin-mermaid/) - Mermaid diagram rendering for VitePress.
- [Mermaid](https://mermaid.js.org/) - Text-based diagram syntax used for architecture flows.
- [GitHub Pages](https://docs.github.com/en/pages) - static hosting target for this project's documentation.
- [Redocly CLI](https://redocly.com/docs/cli) - OpenAPI linting used by `npm run specs:validate`.
- [Ajv](https://ajv.js.org/) - JSON Schema validator used for project demo schemas.

## API and Service Development

- [FastAPI](https://fastapi.tiangolo.com/) - Python web framework with OpenAPI generation.
- [GraphQL](https://graphql.org/) - query language and runtime model for APIs.
- [Open Policy Agent](https://www.openpolicyagent.org/) - policy engine for authorization decisions and governance.

## Agent Frameworks

- [LangGraph](https://www.langchain.com/langgraph) - stateful graph-based agent orchestration.
- [CrewAI](https://docs.crewai.com/) - multi-agent crews, flows, memory, and observability.
- [Semantic Kernel Agent Framework](https://learn.microsoft.com/en-us/semantic-kernel/frameworks/agent/) - Microsoft agent framework for enterprise-oriented orchestration.
- [Agent Development Kit](https://adk.dev/) - open-source framework for building and deploying agents.

## Memory Systems

- [Chroma](https://docs.trychroma.com/) - vector database for embeddings and retrieval.
- [Qdrant](https://qdrant.tech/documentation/) - vector database and similarity search engine.
- [Weaviate](https://weaviate.io/developers/weaviate) - vector database with hybrid search capabilities.
- [pgvector](https://github.com/pgvector/pgvector) - vector similarity search for PostgreSQL.
- [Neo4j](https://neo4j.com/docs/) - graph database for entity and relationship modeling.

## Model Providers and Runtimes

- [OpenAI API](https://platform.openai.com/docs) - Hosted model API documentation for OpenAI platform capabilities.
- [Gemini API](https://ai.google.dev/gemini-api/docs) - Google developer documentation for Gemini API usage.
- [Anthropic Claude](https://docs.anthropic.com/) - Anthropic documentation for Claude API usage and platform features.
- [Ollama](https://ollama.com/docs) - Local model runtime documentation.
- [llama.cpp](https://github.com/ggml-org/llama.cpp) - Local LLM inference source repository.
- [vLLM](https://docs.vllm.ai/) - High-throughput model serving documentation.
- [LiteLLM](https://docs.litellm.ai/) - model gateway and provider abstraction tooling.
